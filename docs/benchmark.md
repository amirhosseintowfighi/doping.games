## چه چیزی تغییر کرد

1. پنل گیمر، مدیریت و معماری جدا و فقط هنگام باز شدن بار می‌شوند.
2. نسخهٔ ۲۰۰×۳۰۰ کاورها برای تصاویر کوچک و `srcset` برای کارت‌ها.
3. حلقهٔ پارالاکس اول همه چیز را اندازه می‌گیرد و بعد می‌نویسد (بدون محاسبهٔ دوبارهٔ اجباری چیدمان).
4. پیش‌بارگذاری فونت وزیرمتن.
5. خاکستری متن‌های کم‌رنگ به کنتراست ۴٫۵:۱ رسید؛ اسم دسترس‌پذیر خروجی‌ها و کاورها با متن قابل‌مشاهده یکی شد.
6. `robots.txt`، `sitemap.xml`، `llms.txt`، آدرس canonical و تگ‌های Open Graph.

## چرا LCP موبایل بهتر نشد و قدم بعدی

بزرگ‌ترین محتوای صفحه تیتر «پینگت رو دوپینگ کن» است. سایت سمت کاربر با React ساخته می‌شود، پس تیتر تا دانلود و اجرای جاوااسکریپت نمایش داده نمی‌شود. الان تیتر زودتر با فونت جایگزین ظاهر می‌شود (FCP ۱٫۸ ثانیه) و وقتی وزیرمتن رسید دوباره رسم می‌شود؛ Lighthouse این رسم دوم را LCP حساب می‌کند.

پیشنهاد به ترتیب اثر:

1. **پیش‌رندر HTML صفحهٔ اصلی هنگام ساخت (SSG)** تا تیتر و بخش بالا بدون منتظر ماندن برای جاوااسکریپت نمایش داده شوند. بیشترین اثر را روی FCP و LCP موبایل دارد.
2. **فونت جایگزین هم‌اندازه با وزیرمتن** (`size-adjust` و `ascent-override`) تا عوض شدن فونت دوباره‌رسم و جابه‌جایی ایجاد نکند؛ یا زیرمجموعه کردن وزیرمتن فقط برای حروف فارسی.
3. **روی سرور واقعی:** HTTP/2 یا 3، فشرده‌سازی Brotli، کش طولانی برای فایل‌های هش‌دار، و CDN با نود داخل ایران.
